KeyScribe

음성으로 타이핑하세요.

KeyScribe는 음성을 텍스트로 변환해주는 보이스 입력 앱입니다. 네이티브 코드로 최소한의 기능만 구현했기에 가볍고 쾌적합니다. 본인이 사용하는 STT API 서비스를 연결하여 사용하세요.

화면 미리보기

다운로드

macOS 다운로드 Apple Silicon __MACOS_ARM64_SIZE__ 또는 Intel __MACOS_X64_SIZE__ · DMG Windows x64 · 설치 파일 · __WINDOWS_SIZE__

최신 버전 __VERSION__

Windows 설치 파일은 SignPath 서명을 사용합니다.

사용 방법

외부 API 키가 필수입니다. OpenAI ↗ · ElevenLabs ↗ · Groq ↗

  1. 앱을 실행하고 메뉴바 또는 트레이의 설정...에서 ElevenLabs, OpenAI 또는 Groq API 키를 입력합니다.
  2. 마이크 접근을 허용합니다. macOS에서는 손쉬운 사용 권한도 허용합니다.
  3. 입력할 창에 커서를 놓고 오른쪽 Option(macOS) 또는 오른쪽 Alt(Windows)를 누른 채 말합니다. 키를 놓으면 글이 입력됩니다.

설정에서 단축키, 인식 언어, 녹음 종료 방식과 붙여넣기 후 자동 전송 여부를 바꿀 수 있습니다.
